# 🍊 和歌山デイリーニュース (Wakayama Daily News)

和歌山県に関する最新ニュースを毎日自動収集し、さっと読める「3つの要約ポイント」とともに日別アーカイブとして閲覧できる**完全無料**のローカルニュースリーダーシステムです。

---

## 🌟 主な特徴

1. **完全無料・登録不要ですぐ使える**
   - ニュース収集元に **Google News RSS** を使用しているため、有料API契約などは一切不要。
   - 独自のURL解析ロジックにより、Google Newsのリンクから **本来の元記事URL（NHK、紀伊民報、毎日新聞、Yahoo!ニュース等）を復元** します。
   - 記事のメタデータとリード文から **「30秒で読める要点まとめ」** を自動生成。
   
2. **日ごとにデータベースへ蓄積（過去にさかのぼって閲覧可能）**
   - 軽量・高速な **SQLite** を採用し、日々のニュースをすべて手元のPC内に永続保存。
   - 左サイドバーの **日別アーカイブ一覧** や **カレンダー（日付ピッカー）** から、いつでも過去の日付にタイムスリップして当時のニュースを振り返ることができます。

3. **快適な検索・カテゴリ分類**
   - 「白浜」「パンダ」「高校野球」「知事」などのフリーワードでリアルタイム全文検索。
   - 「観光・文化」「社会・事件」「政治・行政」「スポーツ」「経済・産業」に自動分類。

4. **ワンクリックで元記事へ**
   - 要約を読んで気になった記事は「元記事を読む ↗」ボタンを押すだけで、ブラウザの別タブで元記事の全文や写真を確認できます。

5. **オプション: Google Gemini AI要約（無料枠）対応**
   - Google AI Studioで無料発行できるAPIキーを画面右上の「設定⚙」から入力すると、Gemini 2.5 Flash による高品質な箇条書きAI要約に自動グレードアップします（未設定でも標準自動要約で100%無料動作します）。

---

## 🚀 使い方

### 1. アプリの起動
フォルダ内にある **`run.bat`** をダブルクリックするだけです。
自動的にブラウザが立ち上がり、以下の画面が表示されます。
- `http://localhost:8000`

### 2. 最新ニュースの取得
- 画面右上の **「最新ニュース取得」** ボタンをクリックすると、数秒〜十数秒で最新の和歌山関連ニュースを取得・要約し、データベースに追加保存されます。
- アプリを起動したままでも、バックグラウンドで自動的に定期巡回を行います。

### 3. 過去ニュースの閲覧
- 左サイドバーの **「日付からさかのぼる」** に表示されている日付をクリックするか、カレンダーピッカーから任意の日付を選ぶと、その日のニュース一覧が表示されます。

## ⏰ 完全自動化（PC起動時や毎朝自動で集めておく方法）

PCの起動時や毎朝7時などに自動でニュースを収集しておきたい場合は、Windows標準の **「タスク スケジューラ」** を使うと便利です。

1. Windowsのスタートメニューで「タスク スケジューラ」と検索して開きます。
2. 右側のメニューから **「基本タスクの作成」** をクリックします。
3. 名前に「和歌山ニュース自動収集」と入力して「次へ」。
4. トリガーで **「毎日」** （または「コンピューターの起動時」）を選択し、時刻（例: 07:00）を設定。
5. 操作で **「プログラムの開始」** を選択。
6. プログラム/スクリプトの「参照」で、本フォルダ内の **`auto_collect.bat`** を選択。
7. 「完了」を押せば設定完了です。

これでPCを起動している間に指定時刻になると、画面を出さずにバックグラウンドで自動巡回し、データベースへその日のニュースがどんどん蓄積されていきます。

## 📁 フォルダ構成

```
News/
├── run.bat              # アプリ起動ランチャー（ダブルクリックで起動）
├── auto_collect.bat     # バックグラウンド自動収集スクリプト（タスクスケジューラ用）
├── main.py              # FastAPI Webサーバー
├── collector.py         # Google News RSS収集・URL復元・要約生成
├── database.py          # SQLiteデータベース管理
├── requirements.txt     # Python依存パッケージ
├── data/
│   └── wakayama_news.db # 蓄積されるSQLiteデータベース（自動生成）
└── static/              # Web UIフロントエンド
    ├── index.html       # ダッシュボード画面
    ├── style.css        # スタイルシート
    └── app.js           # カレンダー操作・検索・描画ロジック
```
