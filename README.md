# 🍊 和歌山デイリーニュース (Wakayama Daily News)

和歌山県に関する最新ニュースを毎日自動収集し、さっと読める「3つの要約ポイント」とともに日別アーカイブとして閲覧できる**完全無料**のオンラインニュースリーダーです。

🌐 **公開WebサイトURL**:  
👉 **[https://kojiro-nakamura.github.io/wakayama-news/](https://kojiro-nakamura.github.io/wakayama-news/)**

スマートフォン・タブレット・PCのブラウザから、いつでもアクセスできます（スマホの「ホーム画面に追加」やブックマーク推奨）。

---

## 🌟 主な特徴

1. **完全無料・サーバー代0円**
   - **GitHub Pages** による静的Webホスティングで世界中へ高速配信。
   - ニュース収集元には **Google News RSS** を使用（有料API契約不要）。
   - 難読化されたGoogle Newsリンクから **本来の元記事URL（NHK、紀伊民報、毎日新聞、Yahoo!ニュース等）を自動復元**。
   - 記事メタデータと本文から **「30秒で読める要点まとめ」** を自動生成。
   
2. **PCの電源を切っていても毎日自動巡回・更新**
   - **GitHub Actions** のクラウドアクションにより、毎日 **06:00, 12:00, 18:00 (JST)** に自動で最新ニュースを取得・要約・コミット。
   - あなたのPCを起動しておく必要は一切ありません。

3. **日ごとにデータベースへ蓄積（過去にさかのぼって閲覧可能）**
   - 収集されたニュースは日別のJSONアーカイブとしてリポジトリ内に永続保存されます。
   - 左サイドバーの **日別アーカイブ一覧** や **カレンダー（日付ピッカー）** から、いつでも過去の日付にさかのぼって当時のニュースを振り返ることができます。

4. **快適な検索・カテゴリ分類**
   - 「白浜」「パンダ」「高校野球」「知事」などのフリーワードでリアルタイム検索。
   - 「観光・文化」「社会・事件」「政治・行政」「スポーツ」「経済・産業」に自動分類。

5. **ワンクリックで元記事へ**
   - 要約を読んで気になった記事は「元記事を読む ↗」ボタンを押すだけで、別タブで元記事の全文や写真を確認できます。

## 🛠️ プロジェクト構成

```
News/
├── .github/workflows/
│   └── daily_news.yml   # 毎日3回自動実行されるGitHub Actions
├── docs/                # GitHub Pagesとして公開されるWebサイト本体
│   ├── index.html       # ニュースリーダーUI
│   ├── style.css        # スタイルシート
│   ├── app.js           # カレンダー操作・検索・描画ロジック
│   └── data/            # 蓄積されるJSONデータベース
│       ├── index.json   # 日付一覧と統計
│       ├── search_index.json
│       └── dates/       # 各日のニュースデータ (YYYY-MM-DD.json)
├── build_site.py        # ニュース収集＆静的サイトビルダー
├── collector.py         # ニューススクレイピングロジック
├── database.py          # ローカルSQLite管理（ローカル検証用）
├── main.py              # ローカルFastAPIサーバー（ローカル検証用）
└── run.bat              # ローカル起動ランチャー
```
